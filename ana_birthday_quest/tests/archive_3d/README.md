# Archived 3D Tests (Three.js WebGL)

These test files belonged to the legacy Three.js WebGL 3D implementation of *A Sinfonia de Ana Gleice*.
Following the user request (`2026-10-23T01:13:02Z`), the project transitioned to a 100% native 2D Canvas Top-Down Storybook RPG with zero Three.js / WebGL / GLTF dependencies.

Files archived:
- `e2e.3d.js`: Full 3D Three.js mesh & camera test suite
- `mixtape_evolution.3d.js`: 3D celestial parasol flight & companion AI test suite
- `capture_visuals.3d.js`: 3D visual capture tool
- `export_characters.3d.js`: 3D character export scratch script
- `render_characters.3d.js`: 3D character render inspection script
- `test_angles.3d.js`: 3D camera angles inspection script
- `test_glasses_and_toad.3d.js`: 3D glasses removal test script
- `test_low_camera.3d.js`: 3D low camera perspective script
- `test_model_render.3d.js`: 3D model render script
- `test_nodes_order.3d.js`: 3D node hierarchy script
- `test_perfect_alignment.3d.js`: 3D character alignment script

Active test suites for the 2D Storybook RPG:
- `tests/storybook_e2e.spec.js`: 4-tier comprehensive E2E test suite for the 2D Canvas Top-Down RPG
- `tests/challenger_stress.spec.js`: Stress, accessibility, and state invariants suite
